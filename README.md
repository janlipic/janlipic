## 🚀 Featured Projects

### 🌍 GeoMetrics – Geospatial Risk Assessment Platform

**University Team Project**

GeoMetrics is a geospatial platform designed to assess potential environmental and geological hazards affecting properties.

The project combines GIS technologies, data processing, algorithms and AI to provide users with an overview of potential property risks.

**Key Features:**
- Geospatial data processing and analysis
- Property risk assessment and Safety Score (0–100)
- Interactive risk visualization on a map
- Automated PDF report generation
- Multiple application components, including web and desktop applications

**Technologies:** Python, C++, GIS, AI, Blockchain and Web Technologies.

[View Project Repository](https://github.com/ThatSebastjan/GeoMetrics)

### 🏓 NTK Kema Murexin Puconci – Website

**Frontend Development Project**

A modern website frontend developed for a Slovenian table tennis club.

The project focuses on creating a responsive and maintainable web application with a component-based architecture and backend API integration.

**Key Features:**
- Responsive user interface
- Component-based React architecture
- Multiple pages and navigation
- Backend API integration
- Organized and reusable components
- Fallback mock data when the backend is unavailable

**Technologies:** React, TypeScript, Vite, Tailwind CSS, React Router.

**Status:** Development project – not yet publicly deployed.

[View Repository](https://github.com/janlipic/ntk-murexin-website)
